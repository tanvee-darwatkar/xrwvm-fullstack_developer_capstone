# Cars Dealership Web Application

## Repository Name
`xrwvm-fullstack_developer_capstone`

## Project Description
Cars Dealership is a comprehensive full-stack web application designed for a national car retailer in the United States. The application displays dealership branches across various states and allows customers to view dealership details, read customer reviews, and submit their own feedback after logging in.

## Project Architecture
- **Frontend:** React, HTML5, CSS3, JavaScript (ES6+), Bootstrap
- **Backend Framework:** Django (Python)
- **Microservices & Database:** Node.js, Express.js, MongoDB (Dealerships and Reviews data), SQLite (User authentication and Django models)
- **Deployment & Cloud Infrastructure:** Docker, Kubernetes, IBM Cloud Code Engine
- **CI/CD:** GitHub Actions workflows for continuous integration and deployment
- **AI Integration:** Sentiment Analysis microservice for analyzing customer reviews

## Core Features
1. **User Authentication:** Registration, Login, and Logout functionality.
2. **Static Pages:** Fully styled "About Us" and "Contact Us" pages.
3. **Dynamic Content:** Filter dealerships by state and view individual dealer profiles with reviews.
4. **Interactive Submissions:** Logged-in users can submit new reviews for specific dealership locations.
5. **Sentiment Analysis:** Integrates sentiment analysis tools to evaluate customer review feedback automatically.
